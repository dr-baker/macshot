# Security

## Report a vulnerability

Report security issues privately through
[GitHub's vulnerability reporting](https://github.com/dr-baker/macshot/security/advisories/new)
for this fork. Include the affected commit or build, steps to reproduce, and the
potential impact. Keep exploit details out of public issues.

For issues specific to the original Macshot, use the
[upstream security policy](https://github.com/sw33tLie/macshot/blob/main/SECURITY.md).
Report vulnerabilities in Apple frameworks or dependencies to their maintainers.

## Supported code

This project is in development. Fixes target the current `main` branch. Older
development builds may require a rebuild to receive a fix.

Automatic redaction can miss sensitive content. Review a capture before sharing it.
